# Academia AI: página de vendas

Página pública de compra do acesso ao **Academia AI**, um sistema de estudos universitários com IA que roda no claude.ai.

- `index.html`: oferta, preço, QR Code PIX (padrão do Banco Central), link de pagamento com cartão e botão "Avisar que paguei".
- `venda.js`: preço, dados do PIX, link de cartão e WhatsApp para os avisos.
- `comprar.html`: redireciona para a página principal (endereço antigo).

O código do app fica num repositório privado separado.
